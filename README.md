# FM2010 Modding Suite — GLOBAL RELEASE 6.0

**Большая Windows-мастерская для Football Manager 2010: файловый центр, инструменты моддинга, аудит, резервирование, справочник назначений файлов и GitHub-интеграция.**

## Быстрый запуск

1. Распакуй весь архив в отдельную папку. Не запускай BAT непосредственно из ZIP.
2. Установи Python 3.10 или новее с включённым компонентом **Tcl/Tk** и опцией **Add Python to PATH**.
3. Запусти `Start FM2010 Settings.bat`.
4. Выбери папку установки игры, в которой находится `fm.exe`.
5. Открой **GLOBAL WORKBENCH 6.0 · GitHub + справочник файлов**. Все предыдущие мастерские 4.0 и 5.0 остаются доступными.

Для обычной работы сторонние Python-пакеты не нужны. Для GitHub-раздела отдельно установи Git for Windows и GitHub CLI (`gh`). См. `GITHUB_GUIDE_RU.md`.

## GLOBAL WORKBENCH 6.0 — новые возможности

### 1. GitHub / Git
- Проверка наличия Git for Windows и GitHub CLI.
- Браузерная авторизация через GitHub CLI в отдельной консоли; Suite не просит и не сохраняет токены.
- Клонирование репозиториев GitHub по HTTPS/SSH, создание локального репозитория и приватного удалённого репозитория.
- `git status`, `git diff`, история коммитов, список веток, создание ветки и настройка автора коммитов.
- Commit, Push, Pull с `--ff-only`, открытие проекта в браузере, создание GitHub Release с ZIP-файлом и запуск мастера Pull Request.
- Генерация `.gitignore` и `README.md`.
- Создание локального Git-репозитория внутри папки установленной игры блокируется; Commit All также блокируется для папки игры и её вложенных каталогов.
- Перед push требуется подтверждение. Перед отправкой обязательно проверь staged-файлы: `.gitignore` не является абсолютной защитой.

### 2. Энциклопедия файлов FM2010
- Допускает индексирование как папки установки, так и отдельной пользовательской папки `Documents\Sports Interactive\Football Manager 2010`.
- Проверяет первые байты файла и не считает `.db` базой SQLite без подтверждающей сигнатуры.
- Индексирует каждый найденный файл выбранной папки: установку игры или пользовательскую папку Documents.
- Для каждой записи показывает путь, расширение, предполагаемый формат, сигнатуру первых байтов, размер, назначение, инструкцию по изменению, рекомендуемый инструмент, уровень риска и уверенность подсказки.
- Контекстные правила для `editor data`, `graphics`, `preferences`, `data/db`, `lnc/all` и отдельных файлов, включая `fm.exe` и `editor data/config.xml`.
- Поддерживаются подсказки по `.xml`, `.dbc`, `.lnc`, `.fmf`, `.dat`, `.fm`, `.sav`, изображениям, аудио, архивам, таблицам, Steam VDF/ACF и другим распространённым типам.
- Фильтр и поиск по каталогу, экспорт полной энциклопедии в CSV.
- Для неизвестных проприетарных форматов назначение явно отмечается как неизвестное; программа не выдаёт догадки за точное описание.

### 3. Глубокий аудит установки
- Поиск 30 самых больших файлов, нулевых файлов, повторяющихся файлов по SHA-256 и файлов без расширений.
- Только отчёт: ничего не удаляется и не перемещается.

### 4. Мастер проекта мода
- Создаёт отдельную структуру папок `editor_data`, `graphics`, `database`, `translations`, `audio`, `docs`, `tests`, `build` и др.
- Создаёт `FM2010_MOD_INFO.json`, README, `.gitignore` и CSV-журнал изменений.
- Оригинальные ресурсы игры не копируются.

### 5. Помощник FM Data Editor
- Поиск `tools/editor/editor.exe`, запуск редактора и открытие папки пользовательских Editor Data.
- Пошаговая инструкция по созданию XML/DBC изменений через редактор.
- Напоминание не перезаписывать системный `config.xml`.

### 6. Проверка совместимости / Pre-flight
- Проверяет выбранный корень установки, наличие `fm.exe` и пользовательской папки Editor Data.
- Показывает найденные XML/DBC-файлы и сохраняет текстовый отчёт с рекомендациями.

### 7. Общая панель
- Быстрый анализ установки и переход ко всем разделам новой мастерской.

## Где хранятся настройки и резервные копии Suite

Обычно `%LOCALAPPDATA%\FM2010SettingsTool\`. Данные приложения отделены от игровых файлов. Внутри находятся настройки, backup, журналы, профили, манифесты операций и карантин.

## Проверка сборки

Запусти `Run Release Checks.bat`. Он выполняет четыре тестовые группы: исходные проверки RELEASE 4.0, workflow-проверки ULTIMATE 5.0, тесты энциклопедии файлов и GUI-интеграции GLOBAL 6.0. Тесты создают временную тестовую папку с фиктивным `fm.exe`, а не меняют твою настоящую установку.

## Важные ограничения

- Для GitHub-интеграции требуются отдельно установленные Git for Windows и GitHub CLI. Без них обычные функции Suite продолжают работать.
- GitHub CLI может хранить учётные данные в системном credential store, но при отсутствии хранилища может использовать файл обычного текста; проверь его документацию и не передавай токены никому.
- Git-репозиторий создавай только в отдельной папке своего мода, не в папке установленной игры. `.gitignore` не заменяет ручную проверку staged-файлов.

- Это файловая мастерская, а не декомпилятор Football Manager 2010. Закрытые игровые форматы и внутренние базы данных `.dat`, `.dbc`, `.fmf` и другие проприетарные ресурсы не редактируются по игровым полям без достоверной спецификации. Для неизвестных бинарных файлов доступны анализ сигнатур, резервирование, замена и HEX-инструменты предыдущих версий.
- SQLite Explorer работает только если файл действительно имеет формат SQLite. Не следует считать, что FM2010 использует SQLite для своих игровых баз.
- Сканер ссылок эвристический; возможны ложные срабатывания.
- HEX-патч без известного смещения и ожидаемых байтов способен повредить ресурс. Проверяй на копии.
- Патчи могут менять игровые ресурсы несовместимым образом. Перед установкой проверяй содержимое архива и используй резервные копии.
- GUI/workflow-тесты проведены на тестовой структуре папок. Они не заменяют проверку на твоей конкретной Steam-установке FM2010 и её патче.

## Состав архива

- `Start FM2010 Settings.bat` — запуск приложения.
- `fm2010_settings_tool.py` — основное приложение и файловый центр.
- `fm2010_release_tools.py` — инструменты RELEASE 4.0.
- `fm2010_advanced_tools.py` — дополнительные инструменты ULTIMATE 5.0.
- `fm2010_release6_tools.py` — GLOBAL RELEASE 6.0: GitHub, справочник файлов, аудит и помощник FM Data Editor.
- `GITHUB_GUIDE_RU.md` и `FILE_ENCYCLOPEDIA_RU.md` — инструкции по GitHub и назначению игровых файлов.
- `tests/` — автоматические тесты.
- `templates/` — стартовый каркас собственного мод-проекта.
- `Run Release Checks.bat` — запуск проверок.
- `Build EXE (optional).bat` — необязательная сборка EXE через PyInstaller.
